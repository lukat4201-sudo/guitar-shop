# 🎸 Online Guitar Shop

An online guitar shop app built with **React + Apollo Client** using a public GraphQL API.

## 🚀 Features
- Browse guitar **brands**
- View **models** with:
  - Search by name
  - Filter by guitar type
  - Infinite scroll
- View detailed **guitar info**:
  - Specs tab
  - Musicians tab (2 at a time with "show more")
- 🌍 Language switcher (English / Macedonian)

## 🛠 Tech Stack
- React + Vite
- Apollo Client (GraphQL)
- React Router
- Framer Motion (animations)
- Lucide Icons
- Tailwind CSS
